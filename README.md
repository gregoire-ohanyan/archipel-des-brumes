# L'Archipel des Brumes

Jeu de négoce et de spéculation dans un archipel noyé de brume : sept îles, une monnaie, des bourses à carnet d'ordres, des rumeurs, des marchands qui se souviennent de vous.

**Jouer :** https://gregoire-ohanyan.github.io/archipel-des-brumes/

## Installer sur un téléphone

- **iPhone** : ouvrir le lien dans Safari → bouton Partager → « Sur l'écran d'accueil ».
- **Android** : ouvrir le lien dans Chrome → menu ⋮ → « Installer l'application ».

Le jeu s'ouvre alors en plein écran, fonctionne hors ligne et garde sa sauvegarde sur l'appareil.

## Contenu du dépôt

- `index.html`, `sw.js`, `manifest.webmanifest`, `icons/` : la web app publiée.
- `source/` : les sources (moteur de simulation, interface, textes d'aide) et `build.py`, qui assemble le tout.
